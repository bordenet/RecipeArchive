## Communication Standards

- **No flattery** - Skip "Great question!" or "Excellent point!"
- **No hype words** - Avoid "revolutionary", "game-changing", "cutting-edge"
- **Evidence-based** - Cite sources, provide data, or qualify as opinion
- **Direct** - State facts without embellishment

### Banned Phrases

| Category | Avoid |
|----------|-------|
| Self-Promotion | production-grade, world-class, enterprise-ready |
| Filler | incredibly, extremely, very, really, truly |
| AI Tells | leverage, utilize, facilitate, streamline, optimize |
| Sycophancy | Happy to help!, Absolutely!, I appreciate... |

### Mobile Builds

| Platform | Script | Critical Notes |
|----------|--------|----------------|
| iOS | `./scripts/ios/build.sh` | Use `xcodebuild` directly, NOT `flutter build ios` |
| Android | `./scripts/android/build.sh` | Use `./gradlew` directly, NOT `flutter build apk` |

**Flutter .env quirk**: Build scripts auto-copy root `.env` → `recipe_archive/.env` (Flutter ignores symlinks).

**Xcode 16**: Script auto-downgrades `objectVersion 70` → `60` for CocoaPods.

### Key File Locations

**iOS Recipe Capture**:
- `recipe_archive/ios/Shared/WebViewContentLoader.swift` — WKWebView loader
- `recipe_archive/ios/RecipeArchive/ShareViewController.swift` — Share Extension

**Android Recipe Capture**:
- `recipe_archive/android/app/src/main/kotlin/.../WebViewContentLoader.kt`
- `recipe_archive/android/app/src/main/kotlin/.../ShareActivity.kt`

**Dart logging**: Use `AppLogger.{category}` from `recipe_archive/utils/app_logger.dart`

### Project Policies

- **Scripts location**: ALL scripts in `./scripts/` at root (never in subdirectories)
- **JS quotes**: Double quotes only (`"`, not `'`) — ESLint enforced
- **No localhost**: Never run Flutter locally; test against production URL
- **10-min timeout**: All long-running operations must timeout
- **Build hygiene**: Never modify source in-place; output to `build/` or `dist/`

### Debugging Escalation

After 5 min OR 3 failed attempts on build errors → generate Perplexity.ai prompt with:
- Exact error, environment (Xcode/OS versions), steps tried

### Multi-Agent Workflow

When reviewing work from other AI agents: **check `git diff` first**, never `git restore` without permission.
